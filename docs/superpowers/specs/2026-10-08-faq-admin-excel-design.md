# Управление FAQ и импорт через Excel

## Цель

Администратор управляет типами FAQ и вопросами через отдельные списки в Telegram-боте или массово через единый Excel-файл. Удаление типа не удаляет его вопросы: они переходят в административный раздел «Без типа» и не показываются клиентам, пока им не назначат активный тип.

## Административное меню

- Убрать кнопку «Инструкции»: текстовые разделы инструкций больше не входят в клиентский путь, потому что инструкции прикреплены к товарам в PDF.
- В разделе «Вопросы и ответы» показать кнопки:
  - «Типы»;
  - «Вопросы»;
  - «Скачать Excel»;
  - «Загрузить Excel»;
  - «Назад».
- Каждый переход заменяет текущий экран через `UiService`; новые блоки сообщений не накапливаются.

## Типы FAQ

- «Типы» открывает отдельный список активных типов и кнопку «Добавить тип».
- При добавлении администратор вводит название и порядок. Постоянный положительный целочисленный ID рассчитывает бот как `MAX(faq_types.id) + 1` внутри транзакционной блокировки.
- Нажатие на тип открывает его карточку с удалением и возвратом к списку.
- Удаление логическое: тип становится неактивным, а все его вопросы получают `type_id = NULL`.
- Удалять или изменять тип из раздела вопросов нельзя.

## Вопросы FAQ

- «Вопросы» сначала открывает список активных типов. Если есть вопросы без типа, первым пунктом показывается «Без типа».
- После выбора типа открывается отдельный список его вопросов и кнопка «Добавить вопрос» для активного типа.
- Карточка вопроса показывает вопрос и ответ. Доступны действия «Перенести в тип», «Удалить» и «Назад».
- Для вопросов без типа доступно назначение активного типа. Новый вопрос нельзя создать без типа.
- Удаление вопроса логическое (`is_active = false`).
- Клиент видит только активные вопросы, связанные с активным типом. Вопросы без типа скрыты.

## Excel-шаблон

Бот формирует `.xlsx` с текущими данными и тремя листами:

1. `Инструкция` — обязательная пошаговая инструкция, допустимые значения, ограничения и примеры.
2. `Типы` — столбцы `ID типа`, `Название`, `Порядок`, `Действие`.
3. `Вопросы` — столбцы `ID вопроса`, `ID типа`, `Вопрос`, `Ответ`, `Порядок`, `Действие`.

На листе `Типы` после текущих записей бот подготавливает 50 строк для новых типов, в которых заполнен только `ID типа`. Значения идут последовательно от актуального `MAX(id) + 1`. Администратор заполняет подготовленные строки сверху вниз без пропусков, не придумывает постоянный ID и может сразу скопировать выданное значение в столбец `ID типа` нового вопроса.

Столбец `Действие` принимает только копируемые текстовые значения:

- `СОХРАНИТЬ` — создать новую запись или обновить существующую;
- `УДАЛИТЬ` — логически удалить запись.

В ячейках будет проверка данных с выпадающим списком, но обычное копирование и вставка текста остаются доступными. Заголовки закреплены, включены фильтры, редактируемые области визуально выделены. На листе `Инструкция` есть легенда ID типов и примеры добавления типа и вопроса в одном файле.

## Импорт

- Бот принимает только `.xlsx` в состоянии загрузки FAQ.
- Сначала файл полностью читается и проверяется без изменения базы.
- Проверяются версия шаблона, названия листов и столбцов, целочисленные ID и порядок, уникальность ID, длины текстов, допустимые действия и ссылки вопросов на существующие или добавляемые в этом же файле типы.
- Новые типы обязаны использовать непрерывные подготовленные ID, начинающиеся с актуального `MAX(id) + 1`. Импорт берёт транзакционную advisory-блокировку; если ID уже заняты параллельным изменением, весь импорт отклоняется с просьбой скачать свежий шаблон.
- Новый вопрос имеет пустой `ID вопроса`; база назначает его автоматически. Существующий вопрос обновляется по положительному `ID вопроса`.
- Строки, отсутствующие в Excel, не изменяются. Удаление происходит только при точном значении `УДАЛИТЬ`.
- Если тип удаляется, связанные вопросы становятся вопросами без типа. Новому вопросу нельзя указать удаляемый тип.
- Все изменения применяются одной транзакцией. При любой ошибке изменений в базе нет; бот возвращает лист, строку и понятное описание ошибки.
- После успеха бот сообщает количества созданных, обновлённых, удалённых и перенесённых в «Без типа» записей.

## Ограничения и безопасность

- Максимальный размер файла: 5 МБ.
- Максимум 2 000 строк вопросов и 500 строк типов в одном импорте.
- Формулы, макросы и внешние ссылки запрещены; импорт принимает только обычные текстовые и целочисленные значения из разрешённых столбцов.
- HTML из Excel не исполняется; весь пользовательский текст экранируется при показе в Telegram.
- Старые таблицы `instruction_sections` не удаляются миграцией, но их неиспользуемый пункт исчезает из админского меню.

## Проверка

- Миграция сохраняет существующие FAQ и разрешает `faq_items.type_id = NULL`.
- Удаление типа сохраняет вопросы и скрывает их от клиента.
- Администратор видит «Без типа», назначает вопросу новый тип и удаляет отдельный вопрос.
- Типы и вопросы доступны через разные списки, а действия с типом доступны только из списка типов.
- Экспорт содержит актуальные данные, инструкцию, легенду, подготовленные ID и значения `СОХРАНИТЬ`/`УДАЛИТЬ`.
- Импорт создаёт тип и связанный с ним вопрос за одну загрузку, обновляет существующие строки и не трогает отсутствующие.
- Ошибка в любой строке, повторный ID или занятый подготовленный ID откатывает весь импорт.
- Повторный импорт одного и того же неизменённого файла идемпотентен для строк с заполненными ID.
